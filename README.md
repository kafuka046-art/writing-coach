# 写作助手 · AI 知识库

一个模拟"人脑知识库"的英语写作学习工具：入库学新表达 + 出库写作检查，对错都自动入库，对标雅思评分能力段，DeepSeek V4 Flash 驱动。

## 包含文件

- `writing-coach-demo.html` — 主程序（单文件，含全部 UI 和逻辑）
- `proxy-server.js` — 本地代理服务器（Node，解决浏览器 CORS 阻止调用 DeepSeek）
- `README.md` — 本说明

## 运行前提

- **Node.js 18+**（用于跑代理服务器，内置 fetch）
  - 检查：命令行输入 `node -v`，看到 v18.x 或更高即可
  - 没装去 https://nodejs.org 下载 LTS 版
- **Chrome 或 Edge 浏览器**（语音输入和麦克风权限需要）
- **DeepSeek API Key**
  - 去 https://platform.deepseek.com/api_keys 申请（有免费额度）

## 启动步骤

### 1. 启动代理服务器

打开命令行（CMD/PowerShell/Git Bash），进入本文件夹，运行：

```bash
node proxy-server.js
```

看到提示 `写作助手代理服务器已启动` 表示成功。**这个窗口不要关**（关了代理就停了）。

### 2. 浏览器打开

访问：

```
http://localhost:8768/
```

⚠️ **不要双击 HTML 文件直接打开**（file:// 协议下麦克风权限受限，语音输入和 API 调用都会失败）。必须通过 localhost 访问。

### 3. 填 API Key

页面顶部「DeepSeek API Key」框填入你的 key → 点「保存」。状态显示「已启用 AI 解释」就对了。

### 4. 开始用

- **入库**：左边贴句子 + 问为什么 → AI 按 8 段教学结构详细解释 → 入库
- **出库**：右边写作文 → AI 检查语法 + 扫描句式 → 用对入库「已掌握」、用错入库「纠错」
- **语音输入**：每个输入框右下角有 🎤 按钮，点一下说话（先选中文/English）

## 功能清单

| 模块 | 功能 |
|------|------|
| 入库·主动请教 | 贴句子 + 问为什么，AI 按 8 段结构详细解释（核心规则→原理拆解→复原语序→混淆对比→补充→仿写→总结） |

| 目标分数过滤 | 设目标后，推荐自动过滤低分表达 |
| 水平分析 | 统计各等级掌握数 + 冲分建议 |
| 题目图片 | Ctrl+V 粘贴或上传题目图片 |
| 语音输入 | 每个输入框右下角 🎤，支持中/英 |
| 数据 | localStorage 本地存 + 导出/导入 JSON 备份 |

## 数据说明

- **知识库数据存在浏览器 localStorage**（绑定你访问的 localhost:8768 这个源）
- 换浏览器/清缓存会丢，**建议定期用「导出库」按钮下载 JSON 备份**
- 新机器用「导入库」上传 JSON 恢复

## 常见问题

**Q: 点语音秒关闭？**
A: 必须用 localhost 访问（不能双击文件），且浏览器要允许麦克风权限。Chrome 语音识别依赖 Google 服务，国内需科学上网；不行就换 Edge 试试，或暂时用打字。

**Q: AI 解释报"Failed to fetch"或"AI 调用失败"？**
A: 代理服务器没跑或没用 localhost 访问。确认：① `node proxy-server.js` 在跑 ② 浏览器访问的是 `http://localhost:8768/` 不是 file://。

**Q: AI 答非所问？**
A: 检查 API Key 是否正确、网络是否通畅。新版本 AI 失败会明确报错，不会再被预设误导。

## 技术栈

- 纯前端：HTML + CSS + 原生 JS（无框架，单文件）
- localStorage 持久化
- DeepSeek V4 Flash API（通过本地 Node 代理转发，绕开浏览器 CORS）
- Web Speech API（语音输入，浏览器原生）
