# Writing Coach 演示脚本（2026-08-19）

## 环境准备
- 本机：coach 目录 `node proxy-server.js` → http://localhost:8768/（已验证可跑）
- 无 Key 演示：内置预设例句库（PRESETS）流程可用；AI 讲解需要 DeepSeek Key
- 面试现场：提前 30 分钟自测，准备录屏兜底

## 30 秒版（口头）
"左侧贴一个句子+问题，AI 按 8 段教学讲解并入库；右侧写作文，自动检查语法和句式，用对自动标已掌握、用错自动记纠错；按目标分数过滤推荐。核心是学用闭环+雅思对标。"

## 2 分钟版（现场操作）
1. 打开 http://localhost:8768/（有 Key 则填入并保存；无 Key 说明"先用内置预设"）
2. 左：贴 "Not only did he fail the exam, but he also lost confidence." → 提问 → 看 8 段讲解 → 入库
3. 右：写一段含该句式的作文 → 检查 → 展示"已掌握/纠错"回流
4. 顶部目标分数过滤（仅高级 7 分）→ 展示推荐变化
5. 导出库 → 展示 JSON 备份

## 5 分钟完整版
- 追加：语音输入（需麦克风权限）、题目图片粘贴、清库后"预设不复活"（数据不丢）、展示 GitHub/README

## 翻车点与规避
| 风险 | 规避 |
|---|---|
| 现场无网络 | 全程走内置预设流程，不依赖 AI |
| 麦克风被禁 | 跳过语音，口头说明 |
| Key 过期 | 提前验证；准备无 Key 预设路径 |
| 端口 8768 被占 | 提前确认空闲，或临时改 PORT |
